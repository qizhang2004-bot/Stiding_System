# 人员导入格式（确定版）

## 一、导入文件

- 格式：Excel（.xlsx）或 CSV（UTF-8），第一行为表头。
- 表头必须包含以下 8 列（列名固定，数据按列顺序解析）。
- 完整导入流程在后续阶段实现；本阶段已提供文件解析与行级校验预览
  （`apps/personnel/importers.py` + `apps/personnel/validators.py`），**不会写入数据库**。

## 二、列定义（固定 8 列，按顺序）

| 列 | 列名 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- | --- |
| 1 | 队组编号 | 是 | 已存在的队组编号（organization_unit.code），确定职工所属队组 | ORG-01 |
| 2 | 班组编号 | 是 | 属于第 1 列队组的班组编号（team.code） | T01-01 |
| 3 | 职工编号 | 是 | 全局唯一，长度 ≤ 50 | E001 |
| 4 | 姓名 | 是 | 长度 ≤ 50 | 张三 |
| 5 | 岗位 | 否 | 长度 ≤ 100 | 值班员 |
| 6 | 班次 | 是 | early（早班）/ middle（中班）/ night（夜班），班组须有该班次配置 | early |
| 7 | 已上班数 | 是 | 当前排班周期（每月 25 日至次月 24 日）已完成的出勤班数，0~32767 整数 | 15 |
| 8 | 矿上应上最少班数 | 是 | 仅用于出勤达标统计/预警，不参与排班算法，0~32767 整数 | 18 |

## 三、校验流程（逐行，按字段顺序）

1. 按第 1 列「队组编号」查询队组。
2. 按第 2 列「班组编号」查询班组。
3. 校验班组是否确实属于第 1 列指定的队组。
4. 校验职工编号是否为空或与现有职工编号重复（文件内重复同样报错）。
5. 校验姓名、岗位、班次等字段。
6. 校验班次是否属于允许的 early / middle / night。
7. 校验已上班数和矿上应上最少班数（非负整数，0~32767）。
8. 复用既有单行校验逻辑（班组状态、数据范围、班次配置存在性），汇总每一行的校验结果。

### 错误提示对照

| 情况 | 提示 |
| --- | --- |
| 队组不存在 | `队组编号不存在：{队组编号}。` |
| 班组不存在 | `班组编号不存在：{班组编号}。` |
| 班组存在但不属于指定队组 | `队组与班组不匹配：班组「{班组编号}」属于「{实际队组}」，不属于「{指定队组}」。` |
| 职工编号为空 / 重复 | `职工编号不能为空。` / `职工编号已存在：{编号}。` / `职工编号在文件内重复：{编号}。` |
| 班次非法 | `班次不合法（应为 early/middle/night）：{值}。` |
| 班数非法 | `已上班数/矿上应上最少班数 必须为整数/不能为负数/超出范围。` |

三种队组/班组类错误分别提示，不会统一显示为“班组不存在”。

## 四、预览与确认写入

- 预览表格展示：队组编号、班组编号、职工编号、姓名、岗位、班次、已上班数、
  矿上应上最少班数、校验结果（失败行逐条列出字段与原因）。
- 「文件行号」为数据在文件中的位置（第 1 行为表头），仅用于定位问题，
  **不是职工工号**。
- **整批校验**：只要存在任何错误行，就不会写入任何职工数据，也不提供确认按钮。
- **确认导入**：全部校验通过后点击确认，系统会在写入前**再次整批校验**，
  然后在单个数据库事务中批量写入；任一冲突（含并发导入造成的职工编号重复，
  由数据库唯一约束兜底）都会整批回滚，不留下部分数据。
- 第 7 列映射 `employee.worked_shifts`；第 8 列映射 `employee.min_required_shifts`
  （仅出勤达标统计，不参与排班算法，也不得替代 `shift_config.required_shifts`）。
- 班次列必须映射到班组真实存在的班次配置（`team.shift_configs`），
  仅凭 early/middle/night 字符串不视为有效。

## 五、其他规则

1. 已上班数属于当前排班周期，不得跨周期累计。
2. 矿上应上最少班数仅用于出勤达标统计；排班目标班数读取班次配置的
   `required_shifts`，两者始终保持独立。
3. 导入时职工的班次配置 = 班组（第 2 列）+ 班次（第 6 列）对应的 `shift_config` 记录。
4. 模板下载（`personnel:import_template`）与校验解析使用同一 8 列结构，
   CSV 与 XLSX 均已实现解析与校验（有自动化测试覆盖）。
