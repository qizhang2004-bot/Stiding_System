# 智慧排班系统

主要架构：Django、google OR-Tools、mysql、Gunicorn、前端通用框架、ECharts、openpyxl

## 子应用

`core`：核心公共功能

`organization`：组织架构管理

`personnel`：人员管理

`scheduler`：排班业务逻辑管理

`reports`：统计报表

`auditlog`：操作日志
